Here's a handy quick-reference for basic Markdown (.md) syntax:

## Text Formatting

  ------------------- ---------------------------------- -------------
  **Bold**            *\*\*text\*\** or *\_\_text\_\_*   **bold**
  *Italic*            *\*text\** or *\_text\_*           *italic*
  ***Bold+Italic***   *\*\*\*text\*\*\**                 ***all***
  ~~Strikethrough~~   *\~\~text\~\~*                     ~~striked~~
  *Inline code*       *\`code\`*                         *print()*
  ------------------- ---------------------------------- -------------

## Headings

\# H1\
\## H2\
\### H3\
\#### H4\
\##### H5\
\###### H6

## Lists

**Unordered** (use *-*, *\**, or *+*)

\- Item 1\
- Item 2\
- Subitem (2 spaces)

**Ordered**

1\. First\
2. Second\
 1. Subitem (3 spaces)

**Task lists**

\- \[x\] Done\
- \[ \] Pending

## Links & Images

\[Link text\](https://example.com)\
\[Link with title\](https://example.com \"Title\")\
\
\![Alt text\](image.jpg)\
\![Alt text\](image.jpg \"Caption\")

## Code Blocks

\`\`\`language\
code block\
\`\`\`

## Blockquotes

\> Quote line 1\
\> Quote line 2\
\>\> Nested quote

## Horizontal Rule

\-\--\
\*\*\*\
\_\_\_

## Tables

\| Header 1 \| Header 2 \|\
\|\-\-\-\-\-\-\-\-\--\|\-\-\-\-\-\-\-\-\--\|\
\| Cell 1 \| Cell 2 \|\
\| Left \| Right \|

Align with *:\-\--* (left), *:\-\--:* (center), *\-\--:* (right)

## Escaping

Use backslash *\\* before special characters:\
*\\\*not italic\\\** → *not italic*

## Useful Shortcuts (common editors)

  --------- --------------------
  Bold      *Ctrl+B* / *Cmd+B*
  Italic    *Ctrl+I* / *Cmd+I*
  Code      *Ctrl+\`*
  Link      *Ctrl+K*
  Preview   *Ctrl+Shift+M*
  --------- --------------------

Keep this nearby and you'll handle 95% of Markdown needs.
